# Política de segurança

A segurança do EditStream Pro é importante.

## Reportar uma vulnerabilidade

Não publique credenciais, dados pessoais, provas de conceito exploráveis ou detalhes sensíveis em issues públicas.

Entre em contato inicialmente pelo Telegram do mantenedor: [@Danielssh](https://t.me/Danielssh), descrevendo o impacto de forma responsável. Aguarde uma resposta antes de divulgar publicamente os detalhes técnicos.

## Boas práticas para colaboradores

- Nunca faça commit de arquivos `.env`, tokens, senhas ou chaves privadas.
- Se uma credencial for exposta, revogue-a e gere outra imediatamente; apagar o arquivo do commit mais recente não invalida a credencial.
- Use contas, dados e chaves de teste em desenvolvimento.
- Não envie dados reais de usuários para logs, issues ou capturas de tela.
- Verifique autorização e permissões no servidor, não apenas na interface.
